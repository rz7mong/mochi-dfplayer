# Sumber desain jam HP

Wajah jam memakai GIF `wajah/default.gif`: wajah putih senyum + kedip (loop 7,2 dtk, 120 ms/frame) dari video.
Urutan: SD `/gif/wajah/default.gif`, lalu versi bawaan di flash (`firmware/assets/builtin/gif/wajah/default.gif`).
Angka tanggal, jam, dan baterai HP digambar di atas GIF itu. Sejak 0.5.6 jam mengikuti delay frame GIF.
`jam-hp.gif` di folder ini = salinan GIF yang sama. Pratinjau: docs/jam-hp.gif
