Instalasi

Belum ada pemasang lewat browser. Firmware DFPlayer belum dipaketkan sebagai berkas .bin. Jangan pakai installer mochi-rzmong: itu firmware MAX98357.

1. Rakit

NetSambungan
TFT SCLKGPIO4
TFT MOSIGPIO6
TFT CSGPIO7
TFT DCGPIO10
TFT RSTGPIO0
BLK3V3
SentuhGPIO1
DFPlayer RXGPIO20 lewat ~1 kΩ
DFPlayer TXGPIO21
DFPlayer VCC5 V
GNDgabung
MPU6050 SDAGPIO5
MPU6050 SCLGPIO3
MPU6050 VCC3V3

MPU6050: SDA GPIO5, SCL GPIO3, VCC 3V3, GND gabung. Tambah resistor 4,7 kΩ dari SDA dan SCL ke 3V3. GPIO2, GPIO8, dan GPIO9 tetap kosong.

2. Kartu DFPlayer

  • 02/001.mp3 sampai 02/018.mp3 untuk 18 klip JPEG
  • 03/001.mp3 notifikasi, 04/001.mp3 dering
  • 05 lagu, 06 suara tema

3. Flash

cd firmware
pio run -e esp32-c3-dfplayer -t upload

Tahan BOOT saat colok USB-C jika unduhan gagal. Port serial memakai USB CDC, bukan UART0.

4. Setelah nyala

  1. Sambungkan Wi-Fi rzmong mochi / rzmong123
  2. Buka http://192.168.4.1/
  3. Pilih tema wajah, gundam, atau mobil, lalu simpan
