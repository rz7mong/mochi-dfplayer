⚠️ GPIO9 adalah pin strap: jangan ditarik ke GND saat boot. GPIO20/21 adalah UART0 bawaan chip; log ESP dibaca lewat USB CDC.

ℹ️ Catatan sentuh: firmware mendeteksi jenis sensor sendiri saat nyala: GPIO1 dibaca sebentar dengan pull-up lalu pull-down, sehingga TTP223 bawaan pabrik (HIGH saat disentuh), TTP223 dengan pad/jumper A disolder (LOW saat disentuh), maupun tombol tekan ke GND langsung jalan tanpa solder apa pun. Syaratnya: jangan sentuh sensor ±1 detik setelah nyala (TTP223 juga mengkalibrasi diri saat itu). Kalau terlanjur dan sensor terbaca tersentuh terus, firmware membalik polaritas sendiri setelah 10 detik. Paksa manual lewat build_flags: -DMOCHI_TOUCH_ACTIVE_HIGH (aktif HIGH) atau -DMOCHI_TOUCH_MODE=2 (aktif LOW + pull-up).

💾 Kartu SD untuk DFPlayer

Isi kartu siap pakai: folder sd/mp3/ di repo (48 file, 1,4 MB). DFPlayer memutar file root menurut urutan salin (file ke-N yang disalin), bukan nama.

1
Format kartu FAT32 (≤ 32 GB). Kartu harus kosong.
2
Salin 0001.mp3 … 0048.mp3 ke root, berurutan satu per satu (jangan seret sekaligus).
3
Sesudahnya buat folder /01 dan salin lagu 001.mp3, 002.mp3, … untuk Pemutar MP3.
# Linux (kartu di /media/SD)
for f in sd/mp3/*.mp3; do cp "$f" /media/SD/; sync; done

# Windows PowerShell (kartu di E:)
Get-ChildItem sd\mp3\*.mp3 | Sort-Object Name | ForEach-Object { Copy-Item $_.FullName E:\ }

  • Nomor yang tidak dipakai berisi MP3 hening. Jangan dihapus: tanpa pengisi urutan bergeser dan suara tertukar.
  • Ganti suara: timpa file bernama sama di sd/mp3/, lalu format dan salin ulang berurutan.
  • Lagu di /01 harus bernomor berurutan tanpa lubang (001, 002, 003 …).
  • Di macOS, hapus ._* dan .DS_Store (dot_clean); ikut terhitung sebagai file.
  • Cek kartu: python firmware/tools/daftar_trek.py --sd /path/kartu. Buat ulang MP3: python3 sd/buat_suara.py.

Semua suara dibuat dari nol oleh sd/buat_suara.py (numpy, tanpa sampel luar, MIT). Opsi --pack mochi-themes.zip memakai WAV asli paket tema mochi-rzmong assets-v1 untuk 14 animasi (paket tanpa lisensi tertulis: untuk kartu sendiri). Build -DMOCHI_DF_MP3_FOLDER: file yang sama di /MP3/0001.mp3 …, dicocokkan dari nama.

⚡ Flash

Paling mudah: pasang dari browser. Atau build sendiri dengan PlatformIO:

cd firmware
pio run -e esp32-c3-dfplayer -t upload

Tahan BOOT saat colok USB-C jika unggahan gagal. Klip animasi ditanam otomatis saat build (perlu Python + Pillow).

🛠️ Kalau ada masalah

GejalaCek
Port tidak munculChrome/Edge di komputer, kabel USB data (bukan kabel cas), tahan BOOT saat colok.
Layar hitamSCLK 4, MOSI 6, DC 3, RST 10, BLK 7. CS modul 8 pin ke GND. Mode berhenti juga hitam: ketuk 1×.
Gambar terbalik / miringMenu → Putar layar.
Tidak ada suaraDFPlayer VCC 5 V, RX lewat 1 kΩ ke GPIO20, TX ke GPIO21, speaker di SPK_1/SPK_2, kartu FAT32 berisi 0001–0048 di root.
Suara tertukarUrutan salin salah: format kartu, salin sd/mp3/ satu per satu berurutan, baru /01.
Suara tidak diulang / lagu tidak lanjutKabel TX modul → GPIO21 membawa pesan "trek selesai". Atau pasang BUSY ke GPIO5 + -DMOCHI_PIN_DF_BUSY=5.
Pemutar: "folder /01 kosong"Lagu harus /01/001.mp3, /01/002.mp3, …
Ketukan tidak terbaca / selalu "tahan"Serial monitor saat nyala menulis sentuh GPIO1: … (jenis yang terdeteksi). Tertulis "tombol ke GND / mengambang" padahal memakai TTP223: kabel I/O putus. Pastikan VCC TTP223 3V3, GND bersama, jangan menyentuh sensor saat menyalakan. Masih salah: paksa -DMOCHI_TOUCH_ACTIVE_HIGH atau -DMOCHI_TOUCH_MODE=2. TTP223 di balik casing: casing ≤ 2 mm, tanpa logam di atas pad.
Bunyi letup / ESP reset saat suara mulaiDaya USB kurang: kabel/charger lebih baik, tambah kapasitor elektrolit 100–470 µF di VCC–GND DFPlayer.
Warna negatif / merah-biru tertukarDi firmware/include/User_Setup_ST7789.h: ganti TFT_INVERSION_ON → TFT_INVERSION_OFF (warna negatif), atau TFT_RGB_ORDER TFT_BGR → TFT_RGB (merah/biru tertukar). Build ulang.
Layar putih / tanpa gambarPastikan modul ST7789 240×240 (bukan 240×320 atau ST7735), VCC 3V3.
Build: No module named PILPasang Pillow ke Python PlatformIO: ~/.platformio/penv/bin/pip install pillow (Windows: %USERPROFILE%\.platformio\penv\Scripts\pip install pillow).
Chronos tidak menemukan perangkatMenu → Chronos BLE harus ON. Nama rzmong dfplayer.
Goyang tidak bereaksiSerial monitor harus menulis MPU6050 siap. SDA 8, SCL 9, alamat 0x68.
