GPIO9 adalah pin strap: jangan ditarik ke GND saat boot. GPIO20/21 adalah UART0 bawaan chip; log ESP dibaca lewat USB CDC.

Catatan sentuh: firmware membaca GPIO1 sebagai LOW = ditekan (pull-up internal). Modul TTP223 bawaan pabrik justru HIGH saat disentuh; solder jumper A agar active-low, atau build dengan -DMOCHI_TOUCH_ACTIVE_HIGH.

💾 Kartu SD untuk DFPlayer

Format FAT32, lalu buat struktur ini. File dicocokkan dari nama, urutan salin tidak penting.

/MP3/0001.mp3 … 0040.mp3   suara animasi (nomor = trek model)
/01/001.mp3 … 255.mp3      lagu untuk Pemutar MP3
/02/001.mp3                suara notifikasi Chronos
/03/001.mp3 …              nada dering panggilan Chronos
Model (ketuk 2×)File /MP3/Klip
1–100001–0010wajah vid_00, vid_01, vid_10, vid_11, vid_20, vid_21, vid_30, vid_31, vid_40, vid_41
11–140011–0014gundam intro, kokpit, tembak, siaga (tahan)
15–180024–0027gundam hujan, isyarat, marah, ledak (goyang)
19–220015–0018mobil car, turbo, headlights, speed_3
23–270019–0023mochi full1, chongmat1 (goyang), video17, video18, xoadau1 (tahan)
28–300034, 0038, 0040dasai video03, video07, video2 (tahan)
  • Lagu di /01 harus bernomor berurutan tanpa lubang (001, 002, 003 …).
  • Di macOS, hapus file ._* dan .DS_Store.
  • Cek kartu: python firmware/tools/daftar_trek.py --sd /path/kartu.

Mode cadangan -DMOCHI_DF_COPY_ORDER: suara animasi di root kartu (0001.mp3 …) dan diputar menurut urutan salin. Salin file root berurutan sebelum folder lain.

⚡ Flash

Paling mudah: pasang dari browser. Atau build sendiri dengan PlatformIO:

cd firmware
pio run -e esp32-c3-dfplayer -t upload

Tahan BOOT saat colok USB-C jika unggahan gagal. Klip animasi ditanam otomatis saat build (perlu Python + Pillow).

🛠️ Kalau ada masalah

GejalaCek
Port tidak munculChrome/Edge di komputer, kabel USB data (bukan kabel cas), tahan BOOT saat colok.
Layar hitamSCLK 4, MOSI 6, DC 3, RST 10, BLK 7. CS modul 8 pin ke GND. Mode berhenti juga hitam: ketuk 1×.
Gambar terbalik / miringMenu → Putar layar.
Tidak ada suaraDFPlayer VCC 5 V, RX lewat 1 kΩ ke GPIO20, TX ke GPIO21, speaker di SPK_1/SPK_2, kartu FAT32, folder /MP3.
Suara tidak diulang / lagu tidak lanjutKabel TX modul → GPIO21 membawa pesan "trek selesai". Atau pasang BUSY ke GPIO5 + -DMOCHI_PIN_DF_BUSY=5.
Pemutar: "folder /01 kosong"Lagu harus /01/001.mp3, /01/002.mp3, …
Ketukan tidak terbaca / selalu "tahan"Polaritas sentuh: lihat catatan TTP223 di atas.
Chronos tidak menemukan perangkatMenu → Chronos BLE harus ON. Nama rzmong dfplayer.
Goyang tidak bereaksiSerial monitor harus menulis MPU6050 siap. SDA 8, SCL 9, alamat 0x68.
