🎞️ Kenapa harus flash ulang?

Semua animasi disimpan sebagai frame JPEG dan ditanam di firmware saat build. Hasilnya tajam dan cepat, tapi tiap animasi baru berarti build + flash ulang. Butuh ganti animasi dari kartu SD tanpa flash? Itu keunggulan Mochi rzmong.

Ruang app 4.128.768 B. Installer 0.8.1 memakai sekitar 95,6% (3.949.136 B), sisa sekitar 180 KB. Angka dari ukuran firmware.bin, bukan laporan build. Klip tambahan akan cepat penuh.

🧪 Langkah

ℹ️ Panduan lengkap langkah demi langkah (GIF, suara di root kartu, musik, Chronos): Animasi & suara.

1
Impor klip ke firmware/assets/builtin/jpeg/<tema>/<nama>.mjpeg + .json:
python tools/import_jpeg_clip.py <tema> <nama> sumber.gif --quality 80
Sumber boleh GIF, folder JPEG/PNG, atau header C. Opsi: --resize, --crop, --step, --hold, --delay.
2
Daftarkan di firmware/assets/meta.json → "jpeg_clips": ["<tema>", "<nama>", "", <trek>]. Peran: "" biasa, "dizzy" saat goyang, "heart" saat tahan. Trek boleh dikosongkan.
3
Build dan flash: cd firmware && pio run -e esp32-c3-dfplayer -t upload.
4
Lihat nomor trek: python tools/daftar_trek.py. Klip baru mendapat trek 0049 dst.; salin 000N.mp3 ke root setelah 0048.

ℹ️ Klip satu tema selalu dikelompokkan; tema baru masuk di akhir urutan model. "boot_theme" di meta.json menentukan model saat nyala.

📦 Kalau flash penuh

tools/embed_jpeg.py punya anggaran byte (custom_jpeg_budget di platformio.ini, sekarang 3.300.000). Jika klip melebihinya, frame yang nyaris sama dengan frame sebelumnya dipakai ulang, mulai dari yang paling mirip. Jumlah frame dan tempo tetap; file aset tidak diubah.

ANGGARAN: 3427066 B > 3300000 B -> frame nyaris sama (<= 0.3% piksel) dipakai ulang, jadi 3262956 B

Jika tetap tidak muat walau ambang 10%, build berhenti dengan pesan. Kurangi klip, atau naikkan anggaran lalu pastikan app masih muat.

🧰 Alat bantu

cd firmware
python tools/daftar_trek.py                  # tabel model → trek → nama file
python tools/daftar_trek.py --sd /media/SD   # cek root 0001-0048, /01 dan sampah macOS

Skrip ini hanya membaca: include/jpeg_clips.h hasil build, atau assets/meta.json jika belum build.
