⚡ Instalasi firmware 0.8.1 dari browser

1
Buka di Chrome atau Edge di komputer (bukan Safari, bukan browser di dalam aplikasi).
2
Tahan BOOT, colok USB-C, lalu lepas BOOT.
3
Klik tombol di bawah, pilih port (USB JTAG/serial debug unit atau ttyACM/COM), lalu Install.
4
Centang Erase untuk pemasangan pertama atau naik dari versi < 0.7.0. Erase menghapus pengaturan (volume, rotasi, Chronos); kartu SD tidak tersentuh.
5
Tunggu sampai 100%, cabut lalu colok lagi. Layar langsung memutar wajah/senyum_kedip. Jangan sentuh sensor ±1 detik saat nyala: firmware sedang mendeteksi jenis sensor sentuh.

⚠️ Browser ini tidak mendukung Web Serial. Pakai Chrome atau Edge di komputer.

⚠️ Halaman harus dibuka lewat https (GitHub Pages) atau localhost.

⚠️ Jangan pakai installer mochi-rzmong untuk rakitan ini: itu firmware amplifier I2S (MAX98357), bukan DFPlayer. Sebaliknya, firmware ini juga tidak cocok untuk rakitan MAX98357.

Isi firmware/firmware.bin: bootloader + tabel partisi + boot_app0 + aplikasi, digabung di offset 0x0 untuk flash 4 MB. Build sendiri: lihat README.

✨ Setelah flash

1
Isi kartu microSD DFPlayer (FAT32, ≤ 32 GB), lalu masukkan sebelum menyalakan: 
/0001.mp3 … /0048.mp3      suara animasi + Chronos (isi sd/mp3/), disalin PERTAMA dan berurutan
/01/001.mp3 … 255.mp3      lagu untuk Pemutar MP3, disalin SESUDAHNYA
Tabel semua nomor dan cara salin: Kartu SD · Animasi & suara.
2
Nyala pertama: lampu latar nyala, wajah/senyum_kedip main dengan suara 0019.mp3. Ketuk 1× = berhenti/putar, ketuk 2× = model berikutnya, tahan 2 dtk = menu.
3
Atur dari menu: volume, Chronos BLE, Jam HP, putar layar. Lihat Cara pakai.

🛠️ Kalau gagal

GejalaCoba ini
Tombol Install tidak muncul / "tidak didukung"Pakai Chrome atau Edge di komputer (Windows, macOS, Linux, ChromeOS). Safari, Firefox, dan browser HP tidak punya Web Serial. Halaman harus https atau localhost.
Port tidak muncul di daftarKabel USB-C harus kabel data, bukan kabel cas. Tahan BOOT saat mencolok, lalu lepas. Coba port USB lain (tanpa hub). Tutup Arduino IDE / serial monitor lain yang memegang port.
Driver CH340 / USB CDCESP32-C3 Super Mini memakai USB CDC bawaan chip (tanpa chip CH340), jadi tidak perlu driver di Windows 10/11, macOS, dan Linux. Hanya papan lain yang punya chip CH340/CP2102 yang butuh driver dari pembuat chip. Linux: tambahkan user ke grup dialout kalau port ditolak.
Gagal di tengah / "Failed to connect"Ulangi dengan BOOT ditahan saat colok. Centang Erase. Kalau tetap gagal, tekan RESET sambil menahan BOOT, lalu lepas RESET dulu baru BOOT.
Layar hitam setelah flashCabut-colok dulu (setelah flash ESP kadang tetap di mode unduh). Cek kabel layar: SCL 4, SDA 6, DC 3, RES 10, BLK 7, VCC 3V3; modul 8 pin CS ke GND. Mode berhenti juga hitam: ketuk 1×.
Layar putih / bergarisKabel SPI terlalu panjang atau RES/DC tertukar. Pendekkan kabel SCL/SDA/DC.
Gambar jalan, tidak ada suaraDFPlayer VCC 5V, GPIO20 → 1 kΩ → RX, TX → GPIO21, speaker di SPK_1/SPK_2, kartu FAT32 berisi 0001–0048 di root, disalin berurutan.
Ketukan tidak terbaca / selalu "tahan"Jenis sensor dideteksi saat nyala; cabut-colok USB tanpa menyentuh sensor. Cek kabel I/O → GPIO1, VCC 3V3. Masih salah: build sendiri dengan -DMOCHI_TOUCH_ACTIVE_HIGH atau -DMOCHI_TOUCH_MODE=2.

Log lewat USB CDC: pio device monitor (115200). Gejala lain: Rakit & kartu SD.

🧑‍💻 Build sendiri (PlatformIO)

pip install platformio pillow
cd firmware
pio run -e esp32-c3-dfplayer -t upload
pio device monitor        # 115200

Opsi di build_flags (platformio.ini): -DMOCHI_TOUCH_ACTIVE_HIGH (paksa sentuh aktif HIGH; bawaan otomatis), -DMOCHI_PIN_DF_BUSY=5 (pin BUSY), -DMOCHI_DEFAULT_ROTATION=0 (layar tegak, pin di atas; bawaan 2). Lihat Diagram kabel.

🍡 Apa ini?

Teman meja kecil: wajah dan klip animasi di layar 1,3 inci, suaranya dari modul DFPlayer Mini yang memutar MP3 dari kartu microSD. Animasi disimpan sebagai frame JPEG penuh warna di flash ESP32, jadi gambarnya lebih tajam daripada GIF 256 warna.

  • 14 model: 6 wajah, 2 mobil, 6 gundam.
  • Suara tiap model diputar sampai habis, lalu diulang.
  • Pemutar MP3 di menu layar untuk lagu di folder /01.
  • Chronos BLE: jam, baterai HP, cuaca, kontrol musik HP, notifikasi, panggilan, navigasi, cari perangkat, alarm, semuanya bersuara.
  • Goyang (opsional, MPU6050) memutar klip "pusing" tema itu.

👆 Gerakan dasar

Ketuk 1×Putar / berhenti (layar hitam, lampu latar mati).
Ketuk 2×Model berikutnya.
Tahan ≥ 0,4 dtkKlip "tahan" tema itu berulang sampai dilepas.
Tahan 2 dtkBuka menu: pemutar MP3, volume, Chronos, Jam HP, rotasi.
