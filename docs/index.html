Mochi DFPlayer

Varian ESP32-C3 + ST7789 1.3" 240×240. Pinout dan perilaku sama pikapet. Ketuk singkat putar/berhenti. Tahan klip hati. Goyang klip pusing. Gambar frame JPEG di flash. Suara DFPlayer Mini.

Halaman instalasi: instalasi.html. Belum ada web-flasher. Flash dari sumber:

cd firmware
pio run -e esp32-c3-dfplayer -t upload

Tema di flash dan web: wajah, gundam, mobil. 18 klip JPEG. DFPlayer folder 02 trek 1-18 mengikuti urutan klip.

Setelah flash

  1. Wi-Fi rzmong mochi / rzmong123
  2. Buka http://192.168.4.1/ untuk tema, Chronos, dan jam HP
  3. Musik: menu di LCD, atau POST /api/music dengan {"action":"play"}
