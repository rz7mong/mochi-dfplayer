🧩 Demo Cara Pemasangan Mochi DFPlayer

Panduan rakit interaktif dengan kabel lepas: ESP32-C3 Super Mini + layar ST7789 1,3" + TTP223 + DFPlayer Mini + speaker 8 Ω, dan MPU6050 kalau mau. Urutannya: daftar komponen, solder modul satu per satu, siapkan kartu SD, flash, lalu uji nyala pertama. Semua pin dicek dengan firmware/include/MochiRzmong.h dan User_Setup_ST7789.h.

🛒 Daftar komponen

ℹ️ Semua modul memakai kabel titik-ke-titik, tanpa PCB. Kabel jumper dupont boleh untuk uji coba di breadboard, tapi untuk rakitan akhir lebih awet disolder.

🔧 Langkah rakit interaktif

Rute kabel di gambar hanya ilustrasi. Yang penting pin ke pin-nya. Tombol keyboard ← → juga bisa dipakai. Diagram lengkap dan tabel ada di Diagram kabel.

💾 Siapkan kartu SD DFPlayer

1
Pakai kartu microSD ≤ 32 GB, format FAT32.
2
Format kartu, salin isi sd/mp3/ ke root berurutan (DFPlayer memakai urutan salin), lalu folder lagu /01. 
/0001.mp3 … /0048.mp3      suara animasi + Chronos, disalin PERTAMA
/01/001.mp3 …              lagu Pemutar MP3, disalin SESUDAHNYA
3
Di macOS, hapus file ._* dan .DS_Store. Cek isi kartu: python firmware/tools/daftar_trek.py --sd /path/ke/kartu.
4
Masukkan kartu ke slot DFPlayer sebelum menyalakan perangkat.

Nomor trek tiap model dan cara menambah suara: Animasi & suara.

⚡ Flash firmware

1
Buka Instalasi firmware di Chrome atau Edge di komputer.
2
Tahan tombol BOOT di ESP32-C3, colok USB-C, lalu lepas BOOT.
3
Klik Install, pilih port, centang Erase untuk pemasangan pertama, tunggu sampai selesai.
4
Cabut lalu colok lagi USB-C.

💡 TTP223 tidak perlu disolder: jenis sensor dideteksi saat nyala. Mau memaksa? Build sendiri dengan -DMOCHI_TOUCH_ACTIVE_HIGH (lihat build sendiri). Pin BUSY ke GPIO5? Tambahkan -DMOCHI_PIN_DF_BUSY=5.

⚠️ Catatan penting

🔊 Jangan pernah menyambung kaki speaker ke GND atau ke GPIO. SPK_1 dan SPK_2 adalah output amplifier jembatan (BTL) di DFPlayer.
⚡ DFPlayer butuh 5V (pin 5V / VBUS ESP). Layar, TTP223, dan MPU6050 tetap 3V3.
📌 GPIO9 pin strap: jangan ditarik ke GND saat boot. GPIO20/21 adalah UART0 chip, log ESP keluar lewat USB CDC.
🔋 Pasang kapasitor 100–470 µF dekat VCC–GND DFPlayer supaya tidak reset atau "plok" saat suara keras.
🔗 Semua GND disatukan: ESP, layar, TTP223, DFPlayer, MPU6050, kapasitor.
📏 Kabel SPI layar (SCL, SDA, DC) sependek mungkin. SPI jalan di 40 MHz; kabel panjang bikin gambar bergaris.
