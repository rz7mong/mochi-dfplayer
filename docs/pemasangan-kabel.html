🗺️ Diagram kabel lengkap

Garis putus-putus = opsional (BUSY). Resistor bergaris putus = 1 kΩ opsional di TX. Rute kabel hanya ilustrasi; yang penting pin ke pin. File gambar: wiring-dfplayer.svg. Mau dirakit langkah demi langkah? Demo rakit.

Versi baterai (tidak mengganti diagram di atas): baterai + modul charge.

📋 Tabel pin

Dicek terhadap firmware 0.7.1: MOCHI_PIN_TFT_SCLK 4, MOCHI_PIN_TFT_MOSI 6, MOCHI_PIN_TFT_DC 3, MOCHI_PIN_TFT_RST 10, MOCHI_PIN_TFT_BL 7, MOCHI_PIN_TFT_CS -1, MOCHI_PIN_TOUCH 1, MOCHI_PIN_DF_TX 20, MOCHI_PIN_DF_RX 21, MOCHI_PIN_DF_BUSY -1 (opsional 5), MOCHI_PIN_MPU_SDA 8, MOCHI_PIN_MPU_SCL 9.

💡 Tips & peringatan

🔊 Jangan pernah menyambung kaki speaker ke GND. SPK_1/SPK_2 adalah output jembatan (BTL). Speaker hanya di antara SPK_1 dan SPK_2.
⚡ DFPlayer di 5V (5V / VBUS). Layar, TTP223, MPU6050 di 3V3. Jangan tertukar.
🧷 GPIO20 → RX lewat 1 kΩ, wajib. TX → GPIO21 boleh langsung atau lewat 1 kΩ.
📌 GPIO9 (SCL MPU6050) pin strap: jangan ditarik ke GND saat boot.
🔋 Kapasitor 100–470 µF dekat VCC–GND DFPlayer: mencegah reset dan bunyi "plok".
🔗 GND bersama: semua GND modul disatukan ke GND ESP.
📏 Kabel SPI pendek (SCL, SDA, DC, RES). SPI 40 MHz; kabel panjang = gambar bergaris atau layar putih.
👆 TTP223: tanpa solder. Firmware mendeteksi aktif HIGH / aktif LOW / tombol ke GND saat nyala; jangan sentuh sensor ±1 detik setelah nyala.

🛠️ Opsi build yang berhubungan dengan kabel

Tulis di akhir build_flags di firmware/platformio.ini, lalu pio run -e esp32-c3-dfplayer -t upload.

FlagKapan dipakai
-DMOCHI_TOUCH_ACTIVE_HIGHPaksa sentuh aktif HIGH (pull-down), lewati deteksi otomatis. -DMOCHI_TOUCH_MODE=2 = paksa aktif LOW + pull-up
-DMOCHI_PIN_DF_BUSY=5Pin BUSY DFPlayer disambung ke GPIO5
-DMOCHI_DEFAULT_ROTATION=0Layar tegak, pin di atas (bawaan 2 = pin di bawah, tatakan GMT130)

Pemasang browser memakai build bawaan: sentuh deteksi otomatis, tanpa BUSY, rotasi 2 (bisa diubah di Menu → Putar layar).
