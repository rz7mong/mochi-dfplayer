🎞️ Tambah animasi GIF

Animasi ditanam di firmware sebagai frame JPEG penuh warna. Alurnya: GIF → impor → daftarkan → build & flash → salin suara.

1
Siapkan GIF 240×240 yang berulang mulus. Simpan sebagai sumber di firmware/assets/builtin/gif/<tema>/<nama>.gif, mis. assets/builtin/gif/wajah/senyum.gif. Tema yang sudah ada: wajah, mobil, gundam; nama tema baru juga boleh.
2
Impor jadi frame JPEG (perlu Python + Pillow): 
cd firmware
python tools/import_jpeg_clip.py wajah senyum assets/builtin/gif/wajah/senyum.gif --quality 80
Hasilnya assets/builtin/jpeg/wajah/senyum.mjpeg + senyum.json. GIF bukan 240×240? Tambahkan --resize 240x240 atau --crop 240x240.
3
Tambahkan di akhir daftar "jpeg_clips" di firmware/assets/meta.json: 
"jpeg_clips": [
  …,
  ["gundam", "pilot", "", 31],
  ["wajah", "senyum", ""]          <- baris baru di akhir
]
Kolom: tema, nama, peran, trek. Peran "" = biasa, "dizzy" = diputar saat goyang, "heart" = diputar saat tahan. Trek boleh dikosongkan: otomatis nomor berikutnya (sekarang 41).
4
Build & flash ulang: pio run -e esp32-c3-dfplayer -t upload. Klip ditanam otomatis saat build. Perhatikan baris ANGGARAN kalau klip banyak (detail anggaran flash).
5
Cek nomor trek: python tools/daftar_trek.py, klip baru mendapat trek 0049 dst. Taruh suaranya sebagai 0049.mp3 dan salin setelah 0048 (lihat urutan salin).

⚠️ Jangan menambah baris di daftar "builtins". Nomor trek builtin = posisinya, jadi baris ke-19 akan memakai trek 19 yang sudah dipakai wajah/senyum_kedip, dan builtin GIF hanya diambil 6 frame.

ℹ️ Klip satu tema selalu dikelompokkan: klip baru tema lama masuk setelah kelompok temanya. "boot_theme" di meta.json menentukan model saat nyala (sekarang wajah, klip senyum_kedip). "theme_order" mengatur urutan tema (sekarang wajah, mobil, gundam; tema yang tidak disebut di akhir). Pakai hanya media yang boleh kamu sebarkan.

🔊 Suara animasi dan Chronos (root kartu, urutan salin)

Isi kartu siap pakai: folder sd/mp3/ di repo (48 file, 1,4 MB). DFPlayer memutar file root menurut urutan salin (file ke-N yang disalin), bukan nama.

1
Format kartu FAT32 (≤ 32 GB). Kartu harus kosong.
2
Salin 0001.mp3 … 0048.mp3 ke root, berurutan satu per satu (jangan seret sekaligus).
3
Sesudahnya buat folder /01 dan salin lagu 001.mp3, 002.mp3, … untuk Pemutar MP3.
# Linux (kartu di /media/SD)
for f in sd/mp3/*.mp3; do cp "$f" /media/SD/; sync; done

# Windows PowerShell (kartu di E:)
Get-ChildItem sd\mp3\*.mp3 | Sort-Object Name | ForEach-Object { Copy-Item $_.FullName E:\ }

  • Suara model diputar sampai habis, lalu diulang selama animasi itu tampil (jeda hening di akhir file mengatur jarak ulang).
  • Klip tahan dan goyang memutar suaranya sendiri, lalu suara model utama mulai lagi.
  • Saat pemutar musik aktif (main atau jeda) atau layar Chronos tampil, animasi tanpa suara.
  • Klip baru otomatis mendapat trek 0049 dan seterusnya (0041–0048 milik Chronos). Salin file itu setelah 0048, sebelum /01.
  • Nomor yang tidak dipakai berisi MP3 hening. Jangan dihapus: tanpa pengisi urutan bergeser dan suara tertukar.
  • Ganti suara: timpa file bernama sama di sd/mp3/, lalu format dan salin ulang berurutan.
  • Lagu di /01 harus bernomor berurutan tanpa lubang (001, 002, 003 …).
  • Di macOS, hapus ._* dan .DS_Store (dot_clean); ikut terhitung sebagai file.
  • Cek kartu: python firmware/tools/daftar_trek.py --sd /path/kartu. Buat ulang MP3: python3 sd/buat_suara.py.

Semua suara dibuat dari nol oleh sd/buat_suara.py (numpy, tanpa sampel luar, MIT). Opsi --pack mochi-themes.zip memakai WAV asli paket tema mochi-rzmong assets-v1 untuk 14 animasi (paket tanpa lisensi tertulis: untuk kartu sendiri). Build -DMOCHI_DF_MP3_FOLDER: file yang sama di /MP3/0001.mp3 …, dicocokkan dari nama.

💡 Suara tidak diulang? Kabel TX DFPlayer → GPIO21 membawa pesan "trek selesai". Atau pasang BUSY ke GPIO5 + -DMOCHI_PIN_DF_BUSY=5.

🎵 Pemutar musik (/01)

1
Salin lagu ke /01/001.mp3, /01/002.mp3, … (maks 255). Nomor harus berurutan tanpa lubang: "berikutnya" setelah lagu terakhir kembali ke 001.
2
Di layar animasi, tahan 2 dtk sampai menu muncul.
3
Sorotan sudah di Pemutar MP3 (item pertama). Ketuk 2× untuk membuka.
4
Sorotan awal di ⏯. Ketuk 1× untuk putar.

🧰 Cek kartu dan nomor trek

cd firmware
python tools/daftar_trek.py                  # tabel model → trek → nama file
python tools/daftar_trek.py --sd /media/SD   # cek root 0001-0048, /01 dan sampah macOS

Skrip ini hanya membaca. Sumbernya include/jpeg_clips.h hasil build, atau assets/meta.json kalau belum build.

⚠️ Di macOS, hapus file ._* dan .DS_Store dari kartu. DFPlayer bisa menghitungnya sebagai trek.
